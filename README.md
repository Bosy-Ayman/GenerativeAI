# Generative Adversarial Networks (DSAI 490) - Spring 2025-2026

Welcome to the repository for the **Generative Adversarial Networks (DSAI 490)** course.

---

## 📂 Repository Structure

- **`Assignments/`**: Implementation of various GAN architectures for course assignments.
- **`Notes/`**: Comprehensive markdown notes detailing algorithms and theory.
  - **`assets/`**: Images and figures supporting the notes.
- **`Questions/`**: Question banks and examples for exam preparation.
- **`Summary/`**: Quick cheat-sheets and high-level summaries of course materials.

## 🚀 Overview
This course dives into the theory and practical implementation of Generative models, Autoencoders, Variational Autoencoders (VAEs), Diffusion Models, and Generative Adversarial Networks (GANs).
